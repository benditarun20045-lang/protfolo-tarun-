# Bendi Tarun - Data Analyst Portfolio

Single-page portfolio built with React, Tailwind CSS (CDN) and inline SVG charts.

## Run
Open `index.html` in a browser (internet needed for the React, Tailwind and font CDNs).

## Deploy (free)
Upload this folder to Netlify Drop, Vercel, or GitHub Pages. `index.html` is the entry point.

## Edit
- Links, phone and email: `LINKS` object near the top of the script in `index.html`
- Projects: `PROJ` array
- Skills: `cats` array inside `Skills()`
- Timeline: `it` array inside `Timeline()`
- Photo: embedded in `index.html`; `assets/profile.jpg` is a copy for reference
